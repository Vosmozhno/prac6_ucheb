# Библиотека — практические работы №2–№5

Flutter Web: каталог, формы и REST API. ПР5 продолжена в папке prac2. Добавлены регистрация, вход, роли, защита маршрутов, сохранение сессии, обновление токенов и выход по времени.

## Запуск

Проверенная среда: Flutter 3.41.7, Dart 3.11.5, Dio 5.11.1, Node.js 22.15.0. Обновлять SDK не требуется. Открыть два терминала в папке проекта.

Сервер (60 секунд жизни access-токена для проверки ПР5):

```bash
node api/mock-server.js --port 8080 --origin http://localhost:5555 --ttl 60
```

Клиент:

```bash
flutter pub get
flutter run -d chrome --web-port=5555 --web-hostname=localhost --dart-define=API_BASE_URL=http://localhost:8080/api
```

Запуск для встроенного браузера:

```bash
flutter run -d web-server --release --web-port=5555 --web-hostname=localhost --dart-define=API_BASE_URL=http://localhost:8080/api --no-web-resources-cdn
```

Открыть http://localhost:5555/. Источник клиента должен совпадать с --origin: localhost и 127.0.0.1 различаются для CORS. GET http://localhost:8080/api/__health проверяет сервер. Шрифты и CanvasKit загружаются локально.

## Учётные записи

| Логин | Пароль | Роль |
|---|---|---|
| reader | reader123 | Читатель: каталог, собственные выдачи и продление |
| librarian | librarian123 | Библиотекарь: каталог, читатели, оформление и закрытие выдач |
| admin | admin123 | Администратор: пользователи, роли, статистика, hard-delete и восстановление |

Новая регистрация создаёт читателя и вложенный билет; пароль должен иметь не менее 8 символов, цифру и специальный символ. Пароли исходных трёх учебных записей сохранены как в контракте API.

Все внутренние экраны требуют входа. После перехода по прямой ссылке приложение запоминает from и возвращает пользователя на исходный адрес. Роли и недоступные действия проверяются отдельно. У читателя собственный экран /my-loans, у библиотекаря /loans, у администратора /admin/users и /admin/stats.

## Сессия

Access и refresh сохраняются в shared_preferences (localStorage), пароль не сохраняется. При запуске пользователь проверяется через /auth/me. При 401 вне /auth/* выполняется одно общее обновление для параллельных запросов, затем исходный запрос повторяется один раз. Ошибка обновления приводит к выходу без рекурсии.

По умолчанию выход происходит после 180 секунд неактивности, предупреждение появляется за 30 секунд. Общая длительность сессии — 1800 секунд (30 минут). Время начала и последнего действия сохраняется, поэтому перезагрузка не продлевает сессию. Клавиатура, мышь, касания и прокрутка учитываются глобально. Для проверки других интервалов существуют параметры сборки SESSION_IDLE_SECONDS, SESSION_WARNING_SECONDS и SESSION_MAX_SECONDS.

Сервер хранит данные в памяти. Перезапуск возвращает исходный каталог и удаляет зарегистрированных пользователей и refresh-токены; после него может потребоваться новый вход. Без --ttl срок access — 900 секунд. Клиентский выход удаляет сессию и отзывает refresh; ранее выпущенный access на сервере остаётся действителен до своего короткого срока истечения.

## Демонстрация клиентской проверки для оценки «5»

В обычной сборке роль восстанавливается через сервер. Учебный режим позволяет показать появление административных кнопок при неизменном токене читателя:

```bash
flutter run -d web-server --release --web-port=5555 --web-hostname=localhost --dart-define=API_BASE_URL=http://localhost:8080/api --dart-define=AUTH_ROLE_DEMO=true --no-web-resources-cdn
```

Войти reader / reader123. В DevTools → Application → Local Storage добавить ключ flutter.auth_ui_role со значением "admin" (JSON-строка с кавычками), затем обновить страницу. В учебной сборке появятся административные разделы и поясняющий баннер; запрос GET /api/users всё равно получит 403, поскольку токен и серверная роль остались читательскими. Не менять access-токен: подделка подписи даст 401 и показывает другой сценарий.

Флаг AUTH_ROLE_DEMO по умолчанию выключен. Полная последовательность, таблица прав и материалы отчёта: [docs/PRACTICE_5.md](docs/PRACTICE_5.md).

## Практическая работа 6

Адаптивная навигация: до 600 px — нижняя панель, от 600 px — компактная боковая,
от 1100 px — боковая с подписями. На 768 px сетки содержат две колонки; на
1920 px рабочая область ограничена 1320 px. На телефоне фильтры книг сворачиваются.

Оптимизации: подмножества трёх шрифтов Roboto, deferred-загрузка разделов учётной
записи и удаление из JavaScript-поставки неиспользуемых Wasm-рендереров и символов
отладки. Полный и Chromium-вариант CanvasKit остаются для разных браузеров.
Исходники шрифтов и лицензия сохранены в tool/fonts-original.

Локальная сборка с тем же подкаталогом, который используется на GitHub Pages:

```bash
flutter build web --release --base-href /prac6_ucheb/ --dart-define=API_BASE_URL=http://localhost:8080/api --no-web-resources-cdn
python3 tool/prepare_web.py
node tool/serve_web.js --base /prac6_ucheb/ --port 5555
```

Открыть http://localhost:5555/prac6_ucheb/. API запустить отдельной командой из начала
README. Сервер tool/serve_web.js поддерживает SPA fallback, включая обновление
страниц по внутренним адресам. Для проверки ошибок остановить API, обновить
каталог, снова запустить API и нажать «Повторить» без перезагрузки браузера.

API_BASE_URL передаётся при сборке. Если параметр не задан, клиент использует
относительный /api на своём хосте. GitHub Pages не запускает Node.js: API
размещается отдельным бесплатным Web Service Render по render.yaml.

GitHub Actions: .github/workflows/pages.yml. После размещения API задать переменную
репозитория API_BASE_URL со значением HTTPS-адреса Render, заканчивающимся на /api,
и выбрать Settings → Pages → Source: GitHub Actions. Push в main запускает
форматирование, анализ, 112 Flutter-тестов, 12 серверных тестов, релиз и публикацию.
Сборка прерывается с понятным сообщением, если HTTPS-адрес API ещё не указан.

Материалы и фактические измерения ПР6: docs/PRACTICE_6.md и docs/practice6/.
