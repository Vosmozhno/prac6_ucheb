Roboto Regular, Medium and Bold were subsetted on 01.11.2026 using Flutter's
bundled HarfBuzz font-subset tool (tool/subset_fonts.py). The original Apache 2.0
license is preserved in Roboto_LICENSE.txt. The modified fonts keep Latin,
Latin Extended, Cyrillic, Cyrillic Supplement, general punctuation, currency
and letterlike symbols. Other scripts use the renderer's font fallback.
